# 🎯 Netlify 배포 - 완전 초보자용 (그림으로 설명!)

## 📸 Step 1: 회원가입 (정말 쉬워요!)

### 화면 설명

Netlify 회원가입 페이지에 들어가면 이렇게 생겼어요:

```
┌─────────────────────────────────────────┐
│        Netlify 로고                      │
│                                         │
│   Sign up for Netlify                  │
│                                         │
│   ┌───────────────────────────────┐   │
│   │  GitHub로 가입 (추천!)        │   │ ← 이거 클릭!
│   └───────────────────────────────┘   │
│                                         │
│   ┌───────────────────────────────┐   │
│   │  GitLab으로 가입              │   │
│   └───────────────────────────────┘   │
│                                         │
│   ┌───────────────────────────────┐   │
│   │  Email로 가입                 │   │
│   └───────────────────────────────┘   │
│                                         │
└─────────────────────────────────────────┘
```

### 🎯 할 일

**GitHub 계정이 있으면:**
1. **"GitHub로 가입"** (또는 "Sign up with GitHub") 버튼 클릭
2. GitHub 로그인 (이미 로그인되어 있으면 자동으로 넘어감)
3. "Authorize Netlify" (Netlify 승인) 버튼 클릭
4. 끝! ✅

**GitHub 계정이 없으면:**
1. **"Email로 가입"** (또는 "Sign up with email") 버튼 클릭
2. 이메일, 비밀번호 입력
3. "Sign up" 클릭
4. 이메일로 온 인증 링크 클릭
5. 끝! ✅

버튼을 클릭하면 이런 화면이 나와요:

```

│  │  Deploy manually              │    │ ← 이거 클릭!

│  └───────────────────────────────┘    │
│                                         │
│  ┌───────────────────────────────┐    │

└─────────────────────────────────────────┘
```

### 🎯 할 일

**"Deploy manually"** 클릭!

- 또는 "Drag and drop"

## 📸 Step 4: 드래그 앤 드롭 화면 (여기가 중요!)

이제 이런 화면이 나와요:

```
┌─────────────────────────────────────────────────┐
│  Deploy site from folder                        │
├─────────────────────────────────────────────────┤
│                                                 │
│  ╔═══════════════════════════════════════════╗ │
│  ║                                           ║ │
│  ║    🗂️                                    ║ │
│  ║                                           ║ │
│  ║    Drag and drop your site folder here   ║ │
│  ║                                           ║ │
│  ║    or                                     ║ │
│  ║                                           ║ │
│  ║    [Browse to upload]                     ║ │
│  ║                                           ║ │
│  ╚═══════════════════════════════════════════╝ │
│                                                 │
│  Deploy without connecting to Git              │
│                                                 │
└─────────────────────────────────────────────────┘
```

### 🎯 할 일

이 큰 박스 안에 `build` 폴더를 드래그!

**방법 1: 드래그 앤 드롭**
1. 다운로드한 `build` 폴더를 찾기
2. 폴더를 클릭한 채로 끌기 (드래그)
3. 위 박스 안에 놓기 (드롭)

**방법 2: 클릭해서 업로드**
1. "Browse to upload" 버튼 클릭
2. 파일 선택 창이 나옴
3. `build` 폴더 선택
4. "열기" 또는 "Upload" 클릭

## ❓ 자주 묻는 질문

### Q1: build 폴더가 어디 있어요?

**A**: 샌드박스에서 다운로드해야 해요!

```
위치: /home/user/webapp/levelmeup-academy/build/
```

**다운로드 방법**:
1. 샌드박스 왼쪽 파일 트리 보기
2. `levelmeup-academy` 폴더 찾기
3. `build` 폴더 찾기
4. 우클릭 → Download

### Q2: 폴더를 드롭했는데 에러가 나요

**A**: 이것들을 확인하세요:

❌ **잘못된 방법**:
- build 폴더 안의 파일들만 선택
- 압축 파일(.zip, .tar.gz) 업로드

✅ **올바른 방법**:
- `build` 폴더 전체를 드래그

### Q3: GitHub로 가입했는데 페이지가 이상해요

**A**: 정상이에요!
- GitHub에서 Netlify 권한 요청
- "Authorize" 또는 "승인" 클릭하면 됩니다

### Q4: 배포는 했는데 사이트가 안 열려요

**A**: 이것들을 해보세요:
1. 2-3분 더 기다리기 (배포 완료 대기)
2. 브라우저 새로고침 (F5)
3. 시크릿 모드로 열기

## 📞 도움이 필요하면?

**어느 단계에서 막히셨나요?**

1. 회원가입이 안 돼요
2. "Add new site" 버튼을 못 찾겠어요
3. "Deploy manually"가 안 보여요
4. 드래그 앤 드롭이 안 돼요
5. 배포 중 에러가 났어요

**지금 어느 단계에 계신가요?**
