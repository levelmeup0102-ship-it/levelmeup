## 🎬 최우선 요청사항: EPIC CINEMATIC 히어로 비디오 (✅ 완료)

사용자님의 요청: "**영상이 더 멋져야함 저기기반이아니라 훨씬더 이펙트 있는 레벨미업 업적 스타워즈처럼**"

### ✨ 구현된 영화 예고편 수준의 이펙트:

#### 🎯 핵심 애니메이션 효과:
1. **epicZoom (20초 루프)**
   - 배경 비디오가 scale(1.2) ↔ scale(1) 사이에서 부드럽게 줌인/줌아웃
   - 2도 회전 효과로 미세한 역동성 추가
   - brightness(1) ↔ brightness(1.1) 빛 효과

2. **particleRise (6-11초 지속)**
   - 6개의 파티클(⭐✨🏆💫🌟⚡)이 화면 하단에서 상단으로 지속적으로 상승
   - 각 파티클마다 다른 지연 시간 (0-5초)
   - translateY(100vh → -100vh) 완전한 수직 이동
   - 투명도 전환으로 자연스러운 나타남/사라짐

3. **explosiveEntry (1.5초)**
   - 모든 UI 요소가 3D 플립(rotateY 180도 → 0도)으로 등장
   - scale(0.3) → scale(1.05) → scale(1) 탄성 효과
   - blur(20px) → blur(0px) 포커싱 효과
   - cubic-bezier(0.68, -0.55, 0.265, 1.55) 탄성 곡선

4. **energyPulse (3초 무한 반복)**
   - 업적 배지들이 금빛 에너지로 펄스 방출
   - 다층 그림자: 40px/80px/120px 레이어
   - 내부 빛(inset shadow)도 함께 펄스
   - box-shadow 강도가 0.8 ↔ 1.0 사이 변화

5. **glow (2-3초 무한 반복)**
   - 타이틀과 텍스트에 4층 금빛 후광
   - text-shadow: 20px/30px/40px/50px/60px 다층 빛
   - 금색(#ffd700)과 오렌지(#ff8c42) 혼합 효과

#### 💎 시각적 강화 요소:

**거대한 타이틀 (LEVEL ME UP)**
- 글자 크기: 6rem → **8rem** (33% 증가!)
- letter-spacing: 8px → **20px** (150% 증가!)
- 4층 text-shadow 효과
- 의사 요소(::before)로 빛나는 그라데이션 레이어 추가
- 공중 부유 애니메이션 (float)

**부제목 (부천 중동 15년 전통 · 명문대 합격의 전설)**
- 글자 크기: 2rem → **2.5rem** (25% 증가!)
- letter-spacing: 1px → **3px** (200% 증가!)
- 3층 발광 효과
- explosiveEntry로 0.3초 지연 등장

**업적 배지 (6개)**
- 테두리: 3px → **4-5px** (두께 증가)
- padding: 25px → **35px** (40% 증가)
- backdrop-filter: blur(10px) → **blur(15px)**
- 호버 시: scale(1.15) + rotate(5deg) + 15px 상승
- 순차적 등장 (0.5초, 0.7초, 0.9초, 1.1초, 1.3초, 1.5초)
- 의사 요소(::before)로 빛 반사 효과

**CTA 버튼 (무료 상담 신청)**
- 글자 크기: 1.5rem → **2rem** (33% 증가!)
- padding: 25px/60px → **30px/70px**
- 테두리: 3px → **5px** (66% 증가)
- 호버 시 물결 효과 (::before 의사 요소)
- 6층 box-shadow (40px/80px 레이어)
- 1초 지연 후 explosiveEntry 등장

#### 🎨 색상 및 조명 시스템:

**배경**
- 완전한 검정색(#000)으로 극대적 대비
- 비디오 위 2층 그라데이션 오버레이:
  - 상단/하단: rgba(0,0,0,0.7) 어둡게
  - 중앙: rgba(0,0,0,0.3) 밝게
  - 방사형 금빛 스포트라이트: rgba(255,215,0,0.1)

**발광 색상 테마**
- 주색상: 금색 #ffd700 (순수 금)
- 보조색: 오렌지 #ff8c42 (따뜻한 빛)
- 그림자: 다층 rgba로 깊이감 극대화

**다층 빛 시스템**
- 1층: 20px blur
- 2층: 40px blur  
- 3층: 60px blur
- 4층: 80px blur
- 5층: 120px blur (일부 요소)
- 각 층마다 투명도와 색상 미세 조정

#### 🚀 성능 최적화:

- **번들 크기**: 112 kB (gzipped) - 이전보다 약간 증가했지만 여전히 최적
- **애니메이션 최적화**: GPU 가속 속성 사용 (transform, opacity)
- **지연 로딩**: 각 요소의 순차적 등장으로 브라우저 부담 분산
- **의사 요소 활용**: 추가 DOM 없이 시각 효과 구현
