## 🚀 수정 후 배포 방법

### Step 1: 파일 수정
- 원하는 파일을 열어서 내용 변경

### Step 2: 빌드
```bash
cd /home/user/webapp/levelmeup-academy
npm run build
```

### Step 3: 배포
1. Netlify 사이트 접속
2. "Deploys" 탭 클릭
3. 새 build 폴더 드래그 앤 드롭
4. 자동 업데이트!

또는:
- 드래그 영역에 새 build 폴더 드롭
- 1-2분 대기
- 완료!
